# Employee-Management-System-CTE-Recursive-CTE
Built a PostgreSQL Employee Management System to practice Common Table Expressions (CTEs), Multiple CTEs, Window Functions, and Recursive CTEs.

📌 Project Overview

This project demonstrates the practical use of Common Table Expressions (CTEs) and Recursive CTEs in PostgreSQL using an Employee Management dataset.

The project focuses on employee salary analysis, department-level statistics, employee ranking, manager-employee relationships, organizational hierarchies, recursive team analysis, and recursive generation of numbers and date ranges.

The project was built as part of my SQL and Data Analytics learning journey to strengthen my ability to write structured, reusable, and analytical SQL queries.

🎯 Objectives

The main objectives of this project are to:

Understand and implement Common Table Expressions (CTEs)
Work with multiple CTEs in a single query
Perform employee and department-level salary analysis
Calculate department statistics using aggregate functions
Identify employees earning above department averages
Find department-wise highest and lowest salaries
Rank employees within departments
Compare employee salaries with company and department averages
Analyze manager and employee relationships
Build organizational hierarchies using Recursive CTEs
Calculate team sizes and reporting structures
Generate sequential numbers using Recursive CTEs
Generate date ranges using Recursive CTEs
